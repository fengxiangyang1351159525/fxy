# 会签通 · 会议活动签到统计工具

一款轻量的会议/活动签到管理工具：组织者创建活动并公布签到码，参会人在现场签到台完成签到入场与签退离场，系统自动统计到勤情况。

## 功能列表

- **活动总览**：全局统计（活动总数、进行中、累计签到/签退人次）、活动卡片列表（状态、时间地点、签到码、签到进度条、删除）
- **创建活动**：活动名称、地点、起止时间；参会人名单逐个添加或批量粘贴导入（支持"姓名,部门"格式）；自动生成现场签到码
- **现场签到台**：输入 6 位签到码（大数字键盘 + 物理键盘支持）→ 搜索参会人姓名或扫描参会人个人二维码 → 一键签到入场 / 一键签退离场，成功后盖章动效并自动复位迎接下一位；名单中无此人时可现场登记并签到
- **二维码签到**：活动二维码（活动详情页展示，扫码直达签到台并自动带码）+ 参会人个人码（个人中心"出示二维码"）→ 现场签到台打开摄像头扫码，自动识别该参会人并完成签到/签退（记录方式为"扫码"）；活动码也可用于多活动快捷切换签到台
- **活动详情统计**（按活动维度）：
  - 统计面板：应到人数、已签到（签到率）、已签退（全程参与率）、未到（平均停留时长）
  - 名单明细：入场/离场时间、登记方式、状态筛选（全部/未签到/已签到/已签退）、姓名部门搜索
  - 手动操作：登记签到、登记签退、重置状态、补充或移出参会人
  - 签到动态流：最近的签到/签退事件倒序展示
- **数据持久化**：全部数据自动保存在浏览器本地，刷新不丢失
- **身份登录体系**：打开应用先选身份（设计者/使用者），再进入账号登录页；本地模拟账号（注册/登录/忘记密码），会话保持到退出
- **源码导出**：顶部导航「导出源码」（设计者可见）一键将全部源代码与文档打包为 zip 压缩包下载，解压后可作为独立 Vite 工程运行

## 登录与权限

### 身份与页面权限

| 页面 | 访问权限 | 说明 |
| --- | --- | --- |
| /welcome 欢迎页 | 公开 | 选择身份：设计者（活动组织方）/ 使用者（参会个人）；已登录访问会自动跳回自己的工作台 |
| /login 登录页 | 公开（需带身份参数） | 登录 / 注册 / 忘记密码三种模式，身份来自上一步选择 |
| / 活动总览 | 仅设计者 | 全部活动、统计总览 |
| /create 新建活动 | 仅设计者 | 创建活动、导入名单、生成签到码 |
| /activity/:id 活动详情 | 仅设计者 | 统计面板、名单管理、手动登记、签到动态 |
| /me 个人中心 | 仅使用者 | 输入签到码加入活动、自助签到/签退、个人出勤记录 |
| /kiosk 现场签到台 | 公开 | 面向会场入口设备与现场访客，无需登录 |

### 完整登录流程

1. 未登录访问任何需要权限的页面 → 自动记录目标页并重定向到欢迎页（页面顶部显示"登录后将继续访问"）。
2. 欢迎页点击身份卡片（同时保存身份标记）→ 进入对应身份的登录页；登录页无身份参数时以上一步保存的标记兜底，二者皆无则回到欢迎页重新选择。
3. 登录页三种模式可切换：登录（默认）、注册（昵称选填，将作为现场登记姓名）、忘记密码（本地重置，顺带解除锁定）。
4. 登录/注册成功 → 若此前是被拦截访问且权限相符，则优先返回原目标页；否则按角色跳转：设计者 → 活动总览，使用者 → 个人中心。
5. 使用者在个人中心输入 6 位签到码加入活动（同名名单记录自动关联，避免重复计数），然后自助签到入场、签退离场。
6. 设计者在活动详情页查看统计；「退出登录」清除会话并回到欢迎页。

### 异常情况一览

- 账号或密码错误：统一提示"账号或密码不正确"，不透露具体哪一项；密码连错 5 次锁定该账号 60 秒，锁定期内按钮进入倒计时。
- "忘记密码"可随时重置密码并解除锁定；重置时账号不存在则提示"未注册该账号"。
- 身份不符：账号已注册为另一身份时，登录页提示"该账号注册的身份是 X，请返回重新选择身份"。
- 重复注册：提示"该账号已被注册，换个账号或直接登录"。
- 角色越权访问：使用者访问设计者页面（或反向）会被自动切换回自己的工作台并提示"身份不符"。
- 使用者输入无效签到码 → "签到码无效"；重复加入同一活动 → "已在活动中"；向已结束的活动加入 → "该活动已结束，无法再加入"。
- 自助签到/签退的时间窗限制：活动未开始时签到按钮停用并显示开始时间；活动已结束后自助操作停用（记录修正由设计者在详情页手动重置）。
- 登录会话与账号数据保存在浏览器本地；清除浏览器缓存会同时清除账号与签到数据（本地模拟的固有影响）。
- 摄像头扫码：需要 HTTPS 环境（或本机 localhost）与摄像头权限；权限被拒、无摄像头 / 被占用时浮层内给出提示并可回退姓名签到。
- 二维码识别范围：识别到的码若指向其它设备的数据（本地模式数据不跨设备），提示"未找到该参会记录 / 该活动签到码无效"；扫码识别到本人已完成出席时提示可由设计者在详情页重置。

## 使用流程

- **设计者**：登录 → 「新建活动」创建会议活动并导入名单 → 公布签到码（详情页可展示活动签到二维码，投屏或打印）→ 可将某设备打开「现场签到台」供现场签到（姓名或扫码）→ 在活动详情页查看统计
- **使用者**：登录 → 个人中心输入签到码加入活动 → 自助签到入场、签退离场（或现场出示"个人参会码"由签到台扫码登记）→ 查看我的出勤记录

## 本地运行（源码压缩包）

本包为完整的 Vite + React 18 + Tailwind CSS v4 工程，请先安装 Node.js 18+，
然后在本目录执行：

    npm install
    npm run dev

开发服务器默认访问 http://localhost:5173。
生产构建：npm run build（产物在 dist/，可部署到任意静态服务器）。

说明：本压缩包为「会签通」完整产品源码与文档；应用为纯前端实现，
账号、登录会话与签到数据均保存在各设备浏览器的 localStorage 中，无后端依赖。
注意：平台内的「导出源码」按钮本身不包含在本包内（属平台专用实现），
包内所有业务源码（含欢迎页/登录/个人中心与权限守卫）均完整可用。
